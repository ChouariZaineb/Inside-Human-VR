# Dossier de presse — Inside Human VR

**Inside Human VR** est une application de réalité virtuelle (WebXR) qui fait explorer le corps humain aux élèves : le cœur, les poumons et le cerveau, à travers des missions courtes.

## En une phrase
Un voyage immersif dans le corps humain, jouable dans un casque autonome ou dans un navigateur, sans installation.

## Le projet
- **Public** : collégiens, lycéens, étudiants et curieux.
- **Principe** : trois niveaux (cœur → poumons → cerveau), chacun avec une phase d'exploration, une mission et un score ; un niveau se débloque quand le précédent est réussi.
- **Points forts** : animations vivantes (battements, respiration, influx nerveux), sons spatialisés, explications lues à voix haute, reprise de partie.
- **Technique** : Three.js (WebGPU), shaders TSL, WebXR, application web progressive (PWA).

- 3 organes, 3 missions, 1 application web.
- Cœur au repos : environ 72 battements/minute ; respiration : environ 15 cycles/minute (valeurs utilisées dans l'application, modifiables).
